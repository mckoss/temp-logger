If compilation fails, install Apple Command Line Tools (xcode-select --install) and Python 3, then retry. For a preview on any platform, run npm run demo.

What are guide zones? The numbered, shaded bands help you compare temperatures at a glance. Their boundaries are chosen by this app and can be edited; they are not Apple safety limits or throttling thresholds. Each card's zone uses its average temperature. The separate “macOS” reading reports the system's thermal pressure.

Apple thermal-state definitions: Nominal = normal limits; Fair = slightly elevated; Serious = high; Critical = significant performance impact. No fixed Celsius boundaries are published here.
